7.5 Declaração de Privacidade

Clique para abrir o registro e marcar o resultado da auditoria.

7 Configure o Website · parte 5 de 8

Para que serve. É o texto que explica o uso dos dados pessoais. Ele aparece no cadastro, no formulário de submissão e numa página pública.

Na Crivo

Abra Sobre → Aviso de Privacidade.

No treinamento

Configurações → Website → Configurar → Declaração de Privacidade

O nome muda de uma Revista para outra. A Crivo pediu uma alteração no código para chamar o texto de Aviso de Privacidade. No pacote oficial do OJS, como no treinamento, a configuração se chama Declaração de Privacidade. A página pública se chama Política de Privacidade.

7.5.1 Preencha ou corrija o texto

  1. Abra Configurações → Website → Configurar → Declaração de Privacidade.
  2. Escolha a aba do idioma no alto do formulário.
  3. Veja se o texto já está certo nesse idioma. Se estiver, marque Conferido.
  4. Se não estiver, escreva ou corrija o texto e clique em Salvar.
  5. No site público, abra a página Política de Privacidade nesse idioma.

Experimente. Compare o texto do treinamento com o Aviso de Privacidade da Crivo em cada idioma e complete o que falta.

Registre na auditoria. Marque como ficou o texto em cada idioma no Registro da auditoria, pelo botão no alto da página.
