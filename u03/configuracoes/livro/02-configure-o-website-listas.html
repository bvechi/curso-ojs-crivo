7.7 Listas

7 Configure o Website · parte 7 de 8

Para que serve. Define quantos itens aparecem de uma vez numa lista do painel antes de o OJS dividir a lista em páginas. Vale para listas como as de submissões, de usuários e de designações editoriais.

No painel

Veja quantas linhas uma lista mostra antes dos números de página no rodapé dela.

No treinamento

Configurações → Website → Configurar → Listas

Os campos da tela Listas.
CampoO que faz
Itens por páginaO número máximo de itens que uma lista mostra numa página. Passou desse número, a lista continua em outra página.
Links de paginaçãoQuantos números de página aparecem na barra que leva às páginas seguintes da lista.

O que pesa na escolha.

  • Um número pequeno obriga a pessoa a passar de página com frequência para achar um item.
  • Um número grande põe mais linhas na tela de uma vez e pode deixar a lista mais lenta para carregar.

Não pratique alterar os valores no treinamento. A mudança vale para todas as listas da Revista, para toda a turma.

Experimente. Sem alterar nada, abra Configurações → Website → Configurar → Listas e anote os dois valores. Depois, abra Usuários & Papéis e veja se a lista de usuários se divide em páginas e quantas linhas mostra em cada uma.
